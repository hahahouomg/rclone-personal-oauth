Personal file management

rclone Personal

A personal setup of rclone for managing the owner's files between Mac, Linux computers, and Google Drive.

Purpose

The owner runs rclone on their own computers to list folders, download files, create backups, and synchronize files as needed. This setup is intended for the owner's personal use.

Google Drive access

The Google OAuth desktop client identifies this setup when the owner authorizes access to Google Drive. The requested Drive permission allows access to file contents and metadata and permits file management operations. The owner chooses which operations to run.

Authorization credentials are stored on the owner's computers. This informational website does not connect to Google Drive or receive its files or access tokens.

Read the Privacy Policy for details about data access, storage, and revoking authorization.

Contact

For questions about authorization, use the support email shown on the Google OAuth consent screen.

This page describes a personal configuration. It does not represent Google or the rclone project.
