rclone Personal

Privacy Policy

Last updated: 7 September 2026

Data access and purpose

rclone Personal is the owner's personal configuration of the rclone command-line application. It requests the Google Drive drive permission to access file contents and metadata and to create, change, copy, or delete files. Access is used for file management operations selected by the owner, including browsing, downloading, backup, and synchronization.

Storage and transfers

OAuth credentials and authorization tokens are stored in configuration files on the owner's computers. File contents and metadata are processed on those computers and exchanged with Google Drive as needed for the selected operations. Files may be retained on the computers or in Google Drive; mounting may also create a local file cache.

This setup does not operate an additional server for collecting Drive data. Google processes data under its own Privacy Policy.

Use and sharing

Google user data is used for the owner's selected file management operations. This setup does not sell that data or use it for advertising or model training. Its use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and retention

The owner can stop rclone and revoke this app's access through Google Account connections. Revoking authorization does not automatically erase file copies already stored on the owner's computers or in Google Drive. The owner controls retention and deletion of those files, configuration files, and caches.

This website

This site contains information only. It does not receive Google Drive credentials, tokens, or files, and includes no analytics scripts or data collection forms. GitHub hosts the site and processes visitor information under the GitHub Privacy Statement.

Contact

Use the support email shown on the Google OAuth consent screen for questions about this personal setup.
